# SingCoach

A local Rust desktop singing coach rebuilt from [the reference brief](docs/rebuild-overview.md). Listen to a piano-style reference, sing a short exercise, pause, and get one correction. Complete five measured repetitions to assess consistency.

## Run

```bash
./run.sh
```

The launcher builds the release binary using the included lockfile and locally cached dependencies. For a first setup without cached crates, run `cargo fetch --locked` with network access first. Linux needs Rust, a C toolchain, ALSA development libraries, and an X11 or Wayland desktop. On Debian/Ubuntu the native build dependencies include `build-essential pkg-config libasound2-dev libxkbcommon-dev libwayland-dev libx11-dev libxi-dev libgl1-mesa-dev`.

On WSL, `run.sh` compiles `platform/windows_player.cs` with the Windows .NET Framework compiler and uses that helper for direct Windows output. The helper is cached next to the release binary. Windows interop and a working WSLg X display are required. No PowerShell is used, and playback never falls back to WSLg audio. Native Linux/Windows/macOS builds use CPAL output. On those platforms you can also use `cargo run --release --locked`.

To isolate output without opening or enumerating a microphone:

```bash
./run.sh --playback-only
```

## Practice

1. Choose a comfortable target and click **Play reference**.
2. For **Clean attack**, sing “ah” for about two seconds, then pause. Technique mode rewards direct entry; performance mode allows a slide and checks confirmed target arrival.
3. For **Two-note transition**, sing one continuous vowel through both pitches, about two seconds each, then pause. Supported intervals are ±2, ±5, and ±7 semitones.
4. Follow the single correction. Only measured attempts count toward the five-attempt set. **New drill** or a configuration change clears that set.
5. The completed set shows mean, standard deviation, best/worst, clean ratio, and reliability (mean minus standard deviation).

All references use the same generated piano-style sound. Exercise notes decay naturally; range guides repeat gently every two seconds until the target changes or you stop.

**Find my range** starts with **your voice**: sing any easy note in your usual voice, without a piano prompt. A brief note of about 0.4 seconds establishes the nearest starting note; some pitch wobble is fine. The piano then guides you higher. Each target needs **one roughly one-second nearby match**, then the piano moves on after time to finish gently and breathe; no silence detection or second confirmation is required. A recent **one-second window with median pitch within ±90 cents** is enough, with brief wobbles and tracking gaps allowed. At least 80% of reliable pitch must stay in the green band (±90 cents). You can keep singing after a missed or unclear attempt; matching never waits for a pause. Silence and clipping reset the window. The green band and “Close enough” label show this relaxed range tolerance. Ordinary technique drills retain their own stricter scoring criteria.

The range guide first gives you **one second to listen**, then time to sing. A one-second in-band match remains sufficient. Once matched, **Hold continues until you release the note**; about 120 ms of quiet or unvoiced input triggers a **one-second breathing pause** immediately, with no leftover singing-slot delay. Background room noise no longer needs to fall below the silence gate. Shorter gaps and clipped input do not release the hold. The Hold card shows a live sustain counter and “Release when ready”; completion includes **Highest sustain**, the longest reliable in-band segment at your highest matched note. Silence, clipping, long tracking gaps and different pitches do not add to the metric. The callout shows “Listen to the piano,” “Matched — finish gently,” and “Matched — take a breath.” Changing to the lower search adds two seconds to breathe before the next piano prompt. Exercise examples play each note for two seconds and leave a longer cooldown afterward; scoring thresholds are unchanged. These timings are app defaults, not a universal textbook standard.

The guide starts with two-semitone steps. After repeated clear misses it uses smaller, one-semitone steps and continues exploring; it does not label the miss as a vocal limit. **Retries are welcome**, including at the starting note. **Struggling — go lower** starts the descent from your highest confirmed note; **Struggling — finish** ends the lower search. After **three piano repetitions without a match** (about six seconds) while climbing, the guide automatically starts descending from your highest matched note. Reliable singing above your initial starting note keeps the climb open, even when you miss the piano target. The timer allows another six seconds after that singing stops, but an unmatched target gets at most twelve seconds total (one extra set of three repetitions). The piano stops after three repetitions (six ready seconds) on each guide, including during a voluntary hold. A successfully matched voluntary hold has no automatic singing cutoff: microphone sustain tracking continues in silence until you release, followed by the usual breathing pause. New guided matches still require active ready playback; use Replay note to retry a stopped starting guide. This skips the unanswered target; it does not count it as reached or identify a vocal limit. During descent, three unanswered repetitions move the guide lower while returning at or above your discovered starting note. Below that starting note, three unanswered repetitions finish with the matched results, instead of continuing through progressively lower prompts. Successful low matches keep exploring lower; unmatched notes never enter the result. You can also choose Finish; C2 remains the supported lower bound. Messages show when to go up or down, the last matched note, and the highest matched note before descent; completion shows both matched endpoints. Completion displays **Suggested practice note: X** and **Try X · target set**. The suggested note is an actually matched note nearest the midpoint of the matched span and is automatically assigned to the exercise target. Comfort is yours to judge; you can choose another target. These are session matches, not a measurement of comfort. The app also changes direction or finishes at its supported C6/C2 bounds.

The completed header includes **Estimate**, a rough range-only comparison, with a hover explanation. A2–F4 produces “Baritone” in this heuristic. It compares the sum of the endpoint distances in semitones, showing alternatives within two semitones of the closest result. Spans shorter than an octave produce no estimate; spans wider than three octaves show “Multiple ranges”; poor endpoint matches remain unclassified. These cutoffs are app heuristics, not validated voice-classification criteria. No gender, timbre, register or comfort is inferred.

Reference spans come from Rochdale Music Service: [Bass D2–E4](https://www.rochdale.gov.uk/rochdale-music-service/learn-bass-voice/2), [Baritone G2–G4](https://www.rochdale.gov.uk/rochdale-music-service/learn-baritone-voice/2), [Tenor C3–B4](https://www.rochdale.gov.uk/rochdale-music-service/learn-tenor-voice/2), [Alto/Contralto E3–F5](https://www.rochdale.gov.uk/rochdale-music-service/learn-contralto-voice/2), [Mezzo-soprano G3–A5](https://www.rochdale.gov.uk/rochdale-music-service/learn-mezzo-soprano-voice/2), and [Soprano B3–C6](https://www.rochdale.gov.uk/rochdale-music-service/learn-soprano-voice/2). These educational reference ranges vary between sources and overlap.

Wear headphones so the piano is not mistaken for your voice. The app supports C2–C6 and reports only the lowest/highest **confirmed matched notes**, with a middle matched note suggested for practice. Finishing requires at least two different confirmed notes. **Finish** applies the result early; cancelling preserves the prior drill. This check does not identify voice type, register, comfort or absolute vocal limits.

**Settings** selects/refreshes microphones and shows the output route. Automatic selection prefers PipeWire, PulseAudio, then the system default, with fallback only on opening errors. Silence does not switch devices. Space toggles the microphone when controls do not own keyboard input. Focused monitor tabs accept left/right arrows.

The header keeps controls/live pitch/range details on the left and a permanent 60 px high instruction cue at the top right, twice the Find my range button height. The cue has a small direction/status icon and action heading with supporting details underneath; full guidance is also available on hover. It stays visible before, during and after a range check, including idle/exercise states. Hold includes the live note and sustain time; highest sustain remains visible in the result summary.

The layout follows the companion `singcoach-codex` project, with a 960×760 default window, compact range/microphone status, large monitor tabs, and exercise/feedback panels below the chart. The chart uses the remaining vertical space; short windows can scroll. The compact and full-scale charts distinguish voice, target, and reference. Compact lanes keep distant voice and target ranges visible with explicit gaps. Prepared reference traces remain pinned for comparison after playback. The spectrogram compares generated reference PCM with microphone spectra on the same frequency/gain scale. Saved guide thumbnails can be selected without changing the exercise or scores; **All notes** returns to the combined reference sequence. Spectral zoom/gain controls are under **Zoom and clarity**. Stop capture to freeze/review the chart; use **Latest** to leave history review. Up to 60,000 voice and reference observations and 24 guides are retained, approximately ten minutes of continuous capture. Data is session-only. No microphone recordings or network services are used. Temporary generated WAVs are cleaned on normal helper replacement/exit; crashes can leave them in the OS temp directory.

During a range check, **Compact** follows your live voice unless you select a thumbnail. The live pane keeps rolling through silence and breathing pauses; saved clips still end at release without trailing silence. Clicking a thumbnail opens that saved clip; automatic target changes return Compact to live singing. Outside an active check, Compact shows one selected/latest singing clip rather than overlaying past attempts. **Full scale** retains the combined session overview. Compact fills its note grid around the target instead of leaving blank rows.

Range review shows your actual singing in blue, with a faint continuous purple guide-note indicator for each saved hold. Thumbnail labels show the median reliable note you actually sang. Saved clips begin at confirmed matching, excluding the approach slide, and stop on release with trailing silence trimmed. Compact fits the selected saved hold across its width rather than centering it. The faint line is only a visual reference, not a recorded piano trajectory. Live range matching keeps its existing green target band; saved voice timing, gaps and measurements are unchanged. Spectrogram retains its saved/current sound-detail panels. Unmatched/empty prompts do not appear as singing entries; visible singing thumbnails are numbered consecutively. Missing/clipped/unreliable voice inside a hold creates gaps; it never copies the piano into your result. Each target keeps up to 1,600 microphone observations (about 16 seconds), within the existing 24-clip session bound; longer sustain metrics continue independently. Full scale fits saved clips across the overview, so its horizontal spacing is a review layout rather than elapsed session time. These captures are session-only pitch/spectrum observations, not saved microphone recordings.

## Melody Coach

Choose **Melody Coach** from the existing **Exercise** selector, alongside Clean attacks and Note transitions. The existing monitor shows a purple piano path with your dashed blue voice on the same timeline. **Compact** fits the melody, **Full scale** shows C2–C6, and **Spectrogram** adds microphone sound detail behind the path. Select the five-note climb (C3 D3 E3 F3 E3, 1/1/1/1/2 seconds) or arpeggio (C3 E3 G3 E3 C3, 1.5/1/1.5/1/2 seconds). Each family has four five-note sequences at similar difficulty. The first Play uses the displayed sequence; later Play presses rotate to the next, updating both the piano path and audio. Changing family or transposition returns to its first sequence. Transpose by semitones within C2–C6. Use the same **play button** as Clean attacks, wearing headphones. The piano plays the whole sequence; its stop icon cancels playback.

For a voice-only attempt, sing while the microphone says **Listening** and the piano is stopped: the first reliable sung frame starts recording immediately at time zero. Use **New drill** to arm another voice-only attempt after results. Silence, unreliable input, playback and cooldown cannot start an attempt.

After playback, sing whenever you are ready: there is no countdown, cooldown or required quiet pause for completed Melody playback. The first reliable sung frame starts the recording at time zero. Wear headphones to keep the piano out of the microphone. Recording uses the microphone timeline for the cursor, target cue and duration. A cursor follows expected time; the dashed blue line shows microphone pitch during the attempt. A separate blue Live note marker also shows fresh reliable pitch outside attempts; it is never scored. The attempt ends automatically after the melody plus 300 ms, or use **Stop attempt**. Press play again to repeat without losing the selected melody. Changing exercise cancels playback and pending melody evidence, and resets the drill just as switching between attacks and transitions does. Monitor tabs preserve the current attempt; the piano path and attempt remain visible in all three views. **New drill** resets the selected exercise. Changing melody/transposition clears the melody result. Microphone interruption invalidates the attempt.

Note rectangles show ✓ green for at least 70% reliable voiced time within the configured pitch tolerance, ! amber otherwise, and ? grey for insufficient evidence. Hover for measurements; results also list signed median bias, median absolute error, reliable voiced coverage and in-tune voiced ratio. One main correction and the hardest assessed note appear in the existing feedback panel. The whole-melody percentage is in-tune time divided by useful expected time, and is withheld unless every note is assessable and complete. Missing voice is never automatically scored zero. Default tolerance is ±35 cents, minimum coverage 50%, with 80 ms excluded at both note boundaries. **Tolerâncias de avaliação** adjusts these defaults before a fresh attempt. This is fixed-time practice, not tempo tracking or DTW; 50 ms analysis windows and uncalibrated input latency limit alignment accuracy. Silence, low confidence, clipping, gaps over 25 ms and suspicious jumps of nine semitones or more break the plotted trace. Clipped notes abstain. Raw pitch frames are retained only for the current attempt, capped at 1,600; no microphone PCM is saved.

Feedback shows a prominent **Score: N / 100**, the percentage of the full assessed melody sung within the selected pitch tolerance. All five notes must have enough reliable evidence; incomplete or unreliable attempts show **Score: — · insufficient data**. Per-note measurements and one correction remain underneath.

Manual acceptance (requires a real desktop/audio device): hear both melodies and their unequal durations; stop playback midway; sing in tune with headphones; deliberately miss one note; remain silent; stop a singing attempt midway; repeat; transpose; switch exercise during playback/waiting/recording; inspect all monitor tabs; restart/select microphone; verify existing attacks, transitions, range checks and monitor views. Under WSL confirm direct Windows playback and no WSLg audio fallback.

## Implementation

- `src/audio.rs`: bounded SPSC capture queue, analysis worker, device errors, native piano instrument, Windows helper protocol, prepared reference PCM.
- `src/piano.rs`: shared allocation-free piano-style synthesis with decaying string partials, overlapping note changes, and gently repeated range guides. No downloaded samples or instrument selector.
- `src/dsp.rs`: custom YIN pitch detection, note math, RMS/clipping and logarithmic spectral measurements.
- `src/melody.rs`: fixed five-note patterns, bounded attempt evidence, time-window assessment. Melody path rendering lives in the shared monitor.
- `src/training.rs`: segmentation, typed exercise configuration, measured/unscored results, attack/transition evaluation and reliability.
- `src/range.rs`: voice-first discovery, independent match confirmation, boundary refinement, automatic descent and explicit matched-range results.
- `src/ui.rs`: desktop UI and explicit practice workflow, adaptive panel sizing, bounded history, asynchronous reference analysis and audio coordination.
- `src/monitor.rs`: presentation adapted from the companion singcoach-codex project: musical pitch lanes, pinned reference traces, monitor tabs, spectral palette, axes and legends.
- `platform/windows_player.cs`: persistent SoundPlayer process with epoch-tagged readiness/errors; connected examples play from one prepared WAV.

Capture callbacks only normalize/mix samples, flag raw clipping, and push into preallocated storage. Analysis runs on a worker at approximately 12 kHz after decimation. A full queue, stream error, or stopped frame flow discards the partial attempt and requires a capture restart. Ordinary scoring is suppressed during reference playback, for 500 ms afterward, and until 250 ms of observed quiet. Guided range confirmation requires the current reference to be ready and ignores microphone frames captured before that readiness; initial voice discovery intentionally runs without reference playback. Native readiness means the callback has begun processing the request; Windows readiness means the helper loaded and requested playback. Neither measures speaker latency or proves audibility.
